# Siliv_plus
Siliv can change unified memory ratio in your mac os. 
Siliv_plus is based on siliv program, but added a few details.

Key change:
1. Added more preset: 26GB & 28GB so you can use LLM without crashing your system.
2. Change the slider so it can be adjusted in 0.5 GB increments. 5GB increments is too big for 32GB mac studio!
